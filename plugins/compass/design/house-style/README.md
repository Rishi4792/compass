# Bundled design system

One system for every Compass page, card and mock, and for every product Compass builds at the Premium or Clean level.

- **Active theme:** `themes/compass-teal.json`. Its CSS form is `templates/tokens.css`; the two carry the same colours, type and radii. A mock inlines `tokens.css` unchanged; the gates in `gates/` read the theme JSON. `neutral-indigo` stays as the generator's reference only.
- **Component recipes:** `SYSTEM.md` Part 2. Compose from them; never invent a control.
- **Who reads this:** the Idea stage when it builds a mock (interview.md, "The look") and the Build stage for every visual step (build/SKILL.md step 3). Not part of the core instruction budget.
